产品能力

从上传文档到给出带来源的回答，完整链路本地闭环

围绕个人知识管理场景设计，关键过程透明可追溯，资料越多，回答越准。

多格式文档解析

支持 PDF、DOCX、Markdown、TXT，自动分块入库，保留文件名、页码等来源信息。

混合检索与重排

BM25 关键词、向量语义、HyDE 查询改写与重排融合，先召回再精排，回答有据可依。

GraphRAG 知识图谱

自动抽取文档实体与关系，检索时注入图谱证据，支持 2D / 3D 图谱和四种视觉设计。

四层记忆系统

会话、短期、长期与用户偏好分层管理，多轮对话保持上下文，回答更贴近个人习惯。

流式对话与工具可视化

SSE 逐字输出，检索、记忆、计算等工具调用独立展示，过程和来源引用一目了然。

多知识库自由管理

数据按知识库隔离，JWT 鉴权与接口限流内置，可配置访问密码，适合多人协作场景。

界面预览

四个核心场景，直接看到真实界面

对话、知识图谱、文档与设置全部集成在同一个桌面应用里。

流式对话

知识库即选即用，工具调用过程独立展示，回答附带来源引用。

2D 知识图谱

文档实体与关系自动抽取，支持搜索、缩放与图例。

3D 知识图谱

球面布局、标签可见，拖拽查看实体之间的关联。

文档管理

拖拽上传、分库管理，解析、向量化与图谱入库自动完成。

知识图谱

从文档自动生长出来的关系网络

图谱由文档自动抽取实体与关系生成，可 2D / 3D 切换，并作为检索证据参与回答。

支持按实体搜索、刷新与重建，2D / 3D 即时切换，四种视觉设计覆盖不同偏好。
